@tm11/mmgeo

Myanmar states, districts & townships

ပြည်နယ် · ခရိုင် · မြို့နယ် — bilingual, with MIMU P-codes

Complete geographic data for Myanmar as a zero-dependency npm package. Every place carries its MIMU P-code, English and Myanmar name, and a stable slug — ready for address forms, validation, and localization. Search accepts Unicode or Zawgyi. ESM + CommonJS, TypeScript types included.

Quick start

import { listStates, listTownships, searchTownships } from '@tm11/mmgeo';

listStates();
// [{ code: 'MMR013', slug: 'yangon-region', name: 'Yangon Region',
//    mm: 'ရန်ကုန်တိုင်းဒေသကြီး', type: 'region', lat: 16.8, lng: 96.15, capital: 'Yangon' }, …]

listTownships('yangon-region', 'yangon-east');  // slug or code: ('MMR013', 'MMR013D002')
// [{ code: 'MMR013009', slug: 'thingangyun', name: 'Thingangyun', mm: 'သင်္ဃန်းကျွန်း', … }, …]

searchTownships('တောင်ကြီး');  // ranked; English, Burmese (Unicode or Zawgyi), slug
// [{ code: 'MMR014001', en: 'Taunggyi', mm: 'တောင်ကြီး',
//    stateSlug: 'shan-state', districtCode: 'MMR014D001', … }]

getByCode('MMR013009');  // any level, by MIMU P-code

API

listStates(opts?)

All 15 states and regions, each with coordinates and capital.

(opts?: { lang?: 'en' | 'mm' }) => StatePlace[]

listDistricts(state, opts?)

Districts and self-administered zones of one state, by slug or code. Returns [] for an unknown state.

(state: string, opts?: { lang?: 'en' | 'mm' }) => DistrictPlace[]

listTownships(state, district?, opts?)

Townships of one district — or of the whole state when district is omitted. Returns [] for unknown refs.

(state: string, district?: string, opts?: { lang?: 'en' | 'mm' }) => TownshipPlace[]

searchTownships(query, opts?)

Ranked search (exact, then prefix, then substring) over English and Myanmar names, slugs and codes. Myanmar input may be Unicode or Zawgyi. Results carry state and district codes for pre-filling a form.

(query: string, opts?: { lang?, limit?, includeSubTownships? }) => TownshipPlace[]

findTownships(input) · getByCode(code)

Exact lookups. findTownships returns every township matching a name, slug or code — more than one means the name is shared (Minhla, Htantabin). getByCode resolves any state, district or township P-code.

(input: string, opts?) => TownshipPlace[]   ·   (code: string, opts?) => AnyPlace | undefined

isValidTownship(input)

Validate user input against the full township list — English, Myanmar (Unicode or Zawgyi), slug, or P-code.

(input: string) => boolean

initialize({ language })

Deprecated. Sets the package-wide default language for the class-based API.

(config: { language: 'en' | 'mm' }) => void

getStates()

Deprecated class-based API: State → District → Township instances with getName() honoring the language set via initialize.

() => State[]

Types

Every returned place shares one shape; name follows the requested language.

Place          { code, slug, name, en, mm }
StatePlace     Place & { level: 'state', type, lat, lng, capital }
DistrictPlace  Place & { level: 'district', type, stateCode, stateSlug }
TownshipPlace  Place & { level: 'township', type, official,
                         stateCode, stateSlug, districtCode, districtSlug }

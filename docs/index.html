@tm11/mmgeo

Myanmar states, districts & townships

ပြည်နယ် · ခရိုင် · မြို့နယ် — bilingual, with stable slugs

Complete geographic data for Myanmar as a zero-dependency npm package. Every place carries its English and Myanmar name plus a stable slug — ready for address forms, validation, and localization. TypeScript types included.

Quick start

import { listStates, listTownships, searchTownships } from '@tm11/mmgeo';

listStates();
// [{ slug: 'yangon-region', name: 'Yangon Region', en: 'Yangon Region',
//    mm: 'ရန်ကုန်တိုင်းဒေသကြီး', lat: 16.8, lng: 96.15, capital: 'Yangon' }, …]

listTownships('yangon-region', 'east-yangon');
// [{ slug: 'thingangyun', name: 'Thingangyun', en: 'Thingangyun', mm: 'သင်္ဃန်းကျွန်း' }, …]

searchTownships('တောင်ကြီး');  // search matches English, Myanmar, or slug
// [{ slug: 'taunggyi', en: 'Taunggyi', mm: 'တောင်ကြီး',
//    stateSlug: 'shan-state', districtSlug: 'taunggyi' }]

API

listStates(opts?)

All 15 states and regions, each with coordinates and capital.

(opts?: { lang?: 'en' | 'mm' }) => StatePlace[]

listDistricts(stateSlug, opts?)

Districts of one state. Returns [] for an unknown slug.

(stateSlug: string, opts?: { lang?: 'en' | 'mm' }) => Place[]

listTownships(stateSlug, districtSlug, opts?)

Townships of one district. Returns [] for unknown slugs.

(stateSlug: string, districtSlug: string, opts?: { lang?: 'en' | 'mm' }) => Place[]

searchTownships(query, opts?)

Find townships by English name, Myanmar name, or slug. Results include the state and district slugs for drill-down.

(query: string, opts?: { lang?: 'en' | 'mm' }) => PlaceWithPath[]

isValidTownship(nameOrSlug)

Validate user input against the full township list — English, Myanmar, or slug.

(nameOrSlug: string) => boolean

initialize({ language })

Set the package-wide default language for the class-based API.

(config: { language: 'en' | 'mm' }) => void

getStates()

Class-based API: State → District → Township instances with getName() honoring the language set via initialize.

() => State[]

Types

Every returned place shares one shape; name follows the requested language.

Place         { slug, name, en, mm }
StatePlace    Place & { lat, lng, capital }
PlaceWithPath Place & { stateSlug, districtSlug }
